  <TabItem label="Debian/Ubuntu">
    Build the package from the repo:

    ```sh
    sudo apt install ./scoot.deb
    ```
  </TabItem>
  <TabItem label="Fedora">
    Build the package from the repo:

    ```sh
    sudo dnf install ./scoot.rpm
    ```
  </TabItem>

<Steps>

1. Start scoot from a VT:

   ```sh
   scoot --tty
   ```

2. Open a terminal with `Super+Return`.

3. Quit with `Super+q`.

</Steps>

<Aside type="caution" title="Login screen">
  Picking scoot at the login screen needs the M0 packaging fix first.
  Until then, start it with `scoot --tty` from a VT.
</Aside>

<Aside type="note">
  The default renderer draws on the CPU and runs everywhere.
</Aside>
